# Проект по практике 3. Композиция в Godot (C#)

## Описание проекта

Проект представляет собой прототип 3D-игры в жанре **Tower Defense / Base Defense**. Игрок находится на игровом поле, отражает атаки противников и может строить защитные башни. Башни помогают справляться с врагами, а задача игрока — продержаться как можно дольше.

Основная цель работы — применение **композиции**: поведение игровых объектов разделяется на отдельные компоненты-узлы, каждый из которых отвечает за свою задачу. Благодаря этому разные объекты могут использовать нужные им компоненты без создания отдельных классов для каждой комбинации поведения.

## Управление

- **W, A, S, D** — перемещение игрока.
- **ЛКМ** — стрельба.
- **ПКМ** — открытие меню строительства.

## Цель игрока

Необходимо выжить как можно дольше, защищаясь от противников. Для этого игроку нужно самостоятельно вести бой и строить башни, которые помогают отражать атаки врагов.

## Технологии

- Godot Engine 4.7
- C#
- .NET SDK

## Структура файловой системы проекта

- В папке **scenes** находятся игровые сцены: главная сцена, игрок, снаряд и башни.
- В папке **scenes/towers** расположены сцены дружественной и вражеской башен.
- В папке **scripts** находятся скрипты игровой логики.
- В папке **scripts/components** расположены скрипты отдельных компонентов игровых объектов.

## Структура проекта

### Основная сцена `main.tscn`

Главная сцена проекта. Содержит игровое поле, игрока, дружественные башни и вражеские башни. Используется как точка входа для запуска игры.

### Сцена игрока `player.tscn`

Содержит игрового персонажа, его визуальную и физическую составляющие, камеру и компонент управления. Компонент управления получает пользовательский ввод и формирует данные, необходимые для управления персонажем.

### Сцена дружественной башни `ally_tower.tscn`

Сцена башни, относящейся к стороне игрока. Она имеет компонент здоровья, компонент обнаружения целей и компонент стрельбы. Башня обнаруживает противников в зоне видимости и атакует их.

### Сцена вражеской башни `enemy_tower.tscn`

Сцена вражеской башни. Помимо здоровья, обнаружения целей и стрельбы, она содержит компонент движения. Благодаря этому башня может перемещаться в сторону выбранной цели и атаковать её.

### Сцена снаряда `bullet.tscn`

Сцена снаряда, создаваемого компонентом стрельбы. Снаряд движется вперёд, обрабатывает столкновение с объектами и наносит им урон.

## Назначение скриптов

- **`Bullet.cs`** — реализует поведение снаряда: перемещение, обработку столкновений, нанесение урона и удаление после попадания или выхода за пределы экрана.
- **`ShootComponent.cs`** — отвечает за стрельбу. Получает цель от указанного компонента, соблюдает интервал между выстрелами и создаёт экземпляры снарядов.
- **`ControllerComponent.cs`** — получает пользовательский ввод для управления игроком и определяет направление движения. Также управляет смещением камеры в зависимости от положения курсора.
- **`HealthComponent.cs`** — отвечает за здоровье игрового объекта. Хранит текущее и максимальное здоровье, обрабатывает получение урона и уничтожает объект при достижении нулевого здоровья.
- **`MoveComponent.cs`** — реализует перемещение объекта в сторону выбранной цели. При достижении заданной дистанции объект останавливается.
- **`VisibilityComponent.cs`** — обнаруживает подходящие объекты в зоне видимости и позволяет получить позицию ближайшей цели.

## Принцип композиции

Каждый компонент отвечает за отдельную часть поведения игрового объекта:

- `ControllerComponent` — получение пользовательского ввода;
- `MoveComponent` — перемещение;
- `ShootComponent` — стрельба;
- `HealthComponent` — здоровье и получение урона;
- `VisibilityComponent` — обнаружение целей;
- `Bullet.cs` — поведение снаряда.

Игровые объекты собираются из необходимых им компонентов. Например, дружественная башня использует здоровье, обнаружение целей и стрельбу, а вражеская дополнительно использует компонент движения. Таким образом, поведение объектов определяется их составом, а общая логика не дублируется в отдельных классах.

## Запуск проекта

1. Установить Godot Engine 4.7 с поддержкой .NET и соответствующий .NET SDK.
2. Открыть в Godot файл `project.godot`.
3. Дождаться импорта ресурсов и сборки C#-проекта.
4. Запустить проект из редактора. Главная сцена — `scenes/main.tscn`.

## Назначение работы

Практика демонстрирует использование композиции в Godot: игровые объекты получают поведение за счёт подключения отдельных компонентов-узлов. Такой подход упрощает повторное использование логики и позволяет гибко собирать объекты с разными наборами возможностей.
